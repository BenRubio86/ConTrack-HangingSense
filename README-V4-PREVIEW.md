# ConTrack-HangingSense V4 UX Preview

This preview belongs to the **BenYimaAI/ConTrack-HangingSense** repository and is based on the actual V3.1 codebase and Hanging Sense brand assets.

Planned/tested preview changes:
- V3.1 local data migration (`contrack_v3_1_state`)
- pain intensity slider/control panel instead of number buttons
- event logging for pee, pain/discomfort, waters/fluid, bleeding and other
- optional event photo stored locally
- combined duration + interval/frequency + pain + event chart
- 1h / 3h / Day / All chart ranges
- unified history timeline with cumulative averages
- full share/download report with chart legend and detailed timeline
- protected new-session flow with backup option including photos
- higher-contrast Hanging Sense visual system
- retention of Hanging Sense branding, BenYima AI creator block, and Doula Silvana contact assets

`main` should remain unchanged until the preview is tested on iPhone.
