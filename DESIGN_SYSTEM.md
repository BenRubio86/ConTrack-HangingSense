## Typography
Primary UI family: **Manrope**, with system fallbacks.

- Product name: 700
- Screen title: 600–700
- Body: 400
- Controls: 600–700
- Timer/KPI: tabular numerals enabled

## UX principles
- Main Track screen remains intentionally sparse.
- Detailed KPIs live in Summary.
- Pain intensity is optional and can be added later.
- No diagnostic predictions.
- Local/offline-first.
- Brand pattern is used sparingly as a signature, not as decoration.
- Color is never the only carrier of meaning.
- Reduced-motion preferences are respected.
