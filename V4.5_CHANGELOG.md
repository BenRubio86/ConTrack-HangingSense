# ConTrack by Hanging Sense — V4.5 Preview

## Implementation order

1. **Data and KPI correctness**
   - Preserve V4.4/V4.3/V3.1 data migration.
   - Average duration and average interval are rolling metrics based on the latest **up to 5** valid values.
   - During a new session, averages use all available values until five values exist.

2. **Editing workflow**
   - Track screen: Edit latest contraction.
   - History: Edit every contraction and event.
   - Contractions: start/end time, pain intensity and note.
   - Events: event type, timestamp, note and photo replacement/removal.

3. **History layout**
   - Compact two-row records.
   - Row 1: timestamp + event type + KPIs.
   - Row 2: rolling averages + note/photo + Edit.
   - Column/header spacing aligned for mobile.

4. **Track rhythm chart**
   - Strictly constrained to the screen width.
   - Latest 5 contractions only.
   - Duration bars and pain intensity values are explicitly identified by a compact legend.

5. **Summary charts**
   - Unified pattern chart: duration, start-to-start interval, pain intensity and event markers.
   - X-axis uses clock time for 1 h / 3 h and appropriate time/date context for Day / All.
   - Adaptive grid spacing based on selected range.
   - Added separate rolling trend chart for Avg Duration (last 5) and Avg Interval (last 5).

6. **Photos**
   - Local IndexedDB storage remains the default.
   - Event photos can be opened from History and Summary.
   - Photo viewer supports iPhone share/save flow.

7. **Reports and export**
   - HTML and PNG reports use the currently selected ConTrack theme.
   - Selected language is used for chart/report labels where available in the language pack.
   - HTML report includes current pattern chart, rolling-average trend chart, timeline, notes and event photos.
   - Brand logo is shown at the top.
   - BenYimaAI creator logo/credit is shown at the lower-left report footer.

8. **More / documentation**
   - Added printable HTML user manual with PDF print/save support.
   - Manual inherits the selected design and language parameter.
   - Added Hanging Sense contact information:
     - 💬 WeChat-ID: HangingSense
     - ✈️ Telegram-ID: HangingSense
     - 📸 Instagram: @hangingsense
     - ✉️ hangingsense@gmail.com

9. **Offline/PWA refresh**
   - V4.5 manifest and new service-worker cache key.
   - V4.5 JS, CSS and user manual are included in the offline cache.

## iPhone regression test sequence

1. Record 6 contractions with different durations/intensity values.
2. Edit latest contraction from Track.
3. Edit an older contraction from History.
4. Add every event type; attach one photo.
5. Open the photo from History and Summary and test Save / Share.
6. Verify rolling Avg Duration and Avg Interval after records 1–6.
7. Test Summary ranges: 1 h, 3 h, Day, All.
8. Verify both charts' time axes and grids.
9. Switch all six visual themes and verify Summary/exports inherit the theme.
10. Switch languages and verify app/report labels.
11. Share HTML report and export PNG.
12. Open the User Manual and use browser Print → Save as PDF.
13. Test Backup + photos, New Session, and Restore Backup.

`main` remains unchanged until this preview passes the regression test.
